## Decisions & Rationale

- **Upgrade before rewrite:** migrating imperative ResumePreview code to runes would be wasted work since the rewrite deletes it; renderer was written directly in runes.
- **zod over hand-rolled guards:** user choice; `.passthrough()` keeps round-trip exports lossless; `theme`/`background` optional in schema for leniency with older exports.
- **Frank Ruhl Libre over keeping TRIAL font:** licensing risk in an open-source repo; slight visual change accepted by user.
- **Tailwind PostCSS route instead of Vite plugin:** hit vitejs/vite#23096 (Vite 8's internal postcss-import resolves bare specifiers before user plugins; fails on SSR builds with ENOENT `<root>/tailwindcss`). Workaround: explicit `@import "tailwindcss/index.css"` in `src/app.pcss` + inline postcss config (external `postcss.config.mjs` needs removed `postcss-load-config` dep).
- **Known caveat from tailwindlabs#19789:** @tailwindcss/vite + Vite 8 LightningCSS settings can mismatch; postcss route sidesteps this.
